用 update_loop 保存完整配置和必要的 Python 脚本。涉及外部服务时先发现已连接的 MCP，检索操作并查看完整参数与返回契约，再直接编排为 MCP 步骤；未连接时引导员工在“连接器”添加或连接后继续。未知读写影响先检查说明再评估。选定的执行 Agent 承担智能任务，确定性处理可使用 Python 或直接命令；不要求每个步骤调用 AI。方法保存在流程配置，具体样例数据放在运行输入。通过结构化引用传递输入、资源与前序产出，不能写死当前机器或某次运行的路径、数值和预期答案。

运行时数量不定的任务，先用确定性步骤筛选数据并产出 JSON 数组，再用 MCP 或 command 的 forEach 逐项执行和汇总；空列表仍正常生成结果，不写死调用次数或样例数据。

只读预览使用员工提供或工具契约明确给出的参数。运行时输入尚未填写时，根据完整契约搭建，不猜测输入反复寻找样例；契约不足时指出具体缺失字段。
