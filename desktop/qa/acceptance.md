# 验收结论

以下是截至 2026-11-02 的历史验证范围摘要，不代表本次整理重新执行了模型任务，也不构成安装包发布批准。原始记录、运行 ID、截图和逐步排查保存在本机归档，不随源码发布。

| 范围 | 已有证据支持的结论 | 边界 |
| --- | --- | --- |
| 本地执行层 | 真实 Codex 在独立样例上完成修复、外部测试与本地补丁交付 | 早期流程使用手工定义，没有真实远程 PR |
| 自然语言与通用流程 | 真实 Pi + DeepSeek 完成生成、试跑、反馈修改、保存和重启恢复；研发样例实际调用 Codex | 针对本地样例的有界验证，不证明任意业务任务都能成功 |
| 自动化 | 真实 Python 采集、定时、目录监听、本机 HTTP、多个 Loop 串联、投递与恢复已有验证；真实模型多轮配置及续聊已有记录 | 部分 Loop 使用手工定义；没有云端常驻、公网长期监听或真实在线文档服务验收 |
| 文件交付 | 曾发现模型将文件路径当正文投递，修正输入读取契约后，真实复验的目标文件与 Loop 产出逐字一致 | 聚焦复验，不等于全面独立验收 |
| 服务错误 | 测试覆盖暂时故障重试上限、认证错误不重试、取消和错误正文不回显；真实对话恢复后完成本地投递 | HTTP 替身测试与真实模型证据分别记录，不保证供应商持续可用 |
| 客户端交互 | 新建、共享输入组件、侧栏调整、历史命令与自动化运行节点完成过有界浏览器或原生窗口检查 | 界面检查不等于新增模型执行能力验证；旧界面细节以当前实现为准 |

开源准备阶段已通过 20 项客户端测试、49 项随包 Python 执行层测试，以及客户端构建、包内手工 Python 流程的执行与重启恢复；没有在该阶段重跑真实模型任务。测试替身、手工流程和真实服务结果不能相互替代。

复验入口见 [验收说明](README.md)，当前发布条件见 [开源发布检查](open-source-release.md)。
