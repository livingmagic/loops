# 正式 Mac 客户端

这里是正式客户端。历史原型只作为本机交互和视觉参考，不包含在公开源码中。

- Electron + React；Pi Agent 使用 DeepSeek。密钥只从本机配置加载，不能回传到页面状态、日志、模型上下文或执行子进程。
- 沿用左侧导航、中心对话、右侧流程与运行记录。流程定义、保存状态和单次运行结果独立。
- 新建 Loop 使用独立创建页：参考 Codex 新聊天页的留白、居中引导和底部输入区；首次发送时自动创建独立工作目录，现阶段不提供手动目录选择。UI 与组件沿用 Loops 的字体、蓝色、边框、圆角和输入组件，不直接照搬 Codex 的控件外观。首次发送后再进入已有 Loop 的对话与流程布局。
- 只有真实进程事件能够推进运行状态；不得预设 AI 回复、成功结果、PR 或测试数字。
- 测试替身只允许在 tests 中通过显式注入使用，生产入口不能切换为演示成功。
- UI 与执行引擎通过受限消息接口连接。网页不能直接运行 shell 或访问本机凭证。
- 运行、保存、配置和失败记录必须持久化。重启后不自动重放提交或创建 PR 等外部操作。
